# Negarit AI mobile

Flutter visitor app. Android is the first target. iOS and web projects are generated so the same UI can run in Chrome.

```powershell
flutter analyze
flutter test
flutter run -d chrome
```

The shell uses the light theme, bundled fonts, and English, Amharic, and Arabic strings. Amharic and Arabic copy in this scaffold still needs a native-speaker review. Venue content, beacons, and payments are not in the app yet.
