# Negarit admin

Operator and merchant dashboard. Sign-in is not connected. The pages are placeholders and do not show venue data.

## Run

From `admin/`:

```powershell
npm run dev
```

The dev server uses port 3001 so it can run beside the API on port 3000. Open http://localhost:3001.

## Check

```powershell
npm run lint
npm run build
```
