# Negarit AI API

NestJS service for the visitor companion. From this directory:

```powershell
npm run start:dev
```

- Health: `GET http://localhost:3000/health`
- OpenAPI: `http://localhost:3000/docs`

```powershell
npm run lint
npm test
npm run test:e2e
npm run build
```

Module folders under `src/` are registered and empty until their features are implemented. Payments and AI providers stay off until credentials exist.
